# SorenCube 🧊

SorenCube is a mobile-first, interactive 3D Rubik's Cube game built using HTML, CSS, and JavaScript.

The project aims to recreate the experience of solving a classic 3×3 Rubik's Cube with realistic visuals, smooth rotations, and intuitive touch controls.

## About

SorenCube is designed to provide an enjoyable and interactive Rubik's Cube solving experience. It focuses on realistic 3D interactions, smooth controls, and puzzle-solving challenges.

## Features

- Interactive 3D Rubik's Cube.
- Classic 3×3 cube design.
- Six traditional cube colours.
- Touch-and-drag controls.
- Smooth cube and face rotations.
- Random cube scrambling.
- Move counter.
- Solving timer.
- Undo and reset functionality.
- Responsive mobile-first interface.

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)

## Development Goals
